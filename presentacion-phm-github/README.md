# Resultados PHM Bienes Raíces — Propiedades.com

Este paquete contiene la presentación en un solo archivo HTML autocontenido
(`index.html`, incluye estilos, fuentes, logos e imágenes ya incrustados,
no depende de ningún otro archivo).

## Ver la presentación
Simplemente abre `index.html` con doble clic en cualquier navegador.

## Publicarla gratis en GitHub Pages
Sigue el paso a paso que te compartió Claude en el chat, o consulta:
https://docs.github.com/es/pages/quickstart

## Descargar como PDF
Una vez abierta en el navegador (o publicada en GitHub Pages), usa el botón
"Descargar PDF" en la parte superior de la página.
